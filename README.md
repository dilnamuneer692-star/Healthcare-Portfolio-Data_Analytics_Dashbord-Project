# Healthcare-Portfolio-Data_Analytics_Dashbord-Project

**Author:** Dilna M  
**Project Type:** Healthcare Data Analytics  
**Tool:** Microsoft Power BI

## 1. Project Overview

This project uses Microsoft Power BI to analyze healthcare data and present insights through six interactive dashboard pages. It focuses on hospital information, patient demographics, clinical analysis, financial performance, and pharmacy-related analysis.

## 2. Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization

## 3. Dashboard Pages

### 1. Hospital Overview
Provides a high-level summary of the healthcare dataset through key performance indicators (KPIs) and visualizations.

### 2. Patient Demographics
Explores patient characteristics, including age distribution and gender distribution, where available.

### 3. Hospital Operations
Presents hospital admission information and operational trends based on the available dataset fields.

### 4. Clinical Analysis
Explores medical conditions and available clinical information to understand patterns within the dataset.

### 5. Financial Performance
Analyzes billing amounts and insurance-related information to explore the financial aspects of healthcare services.

### 6. Pharmacy Analysis
Presents pharmacy-related analysis using the relevant fields available in the dataset.

## 4. Dataset

The project uses a healthcare dataset containing information such as:

- Billing Amount
- Insurance Provider
- Date of Admission
- Other patient and healthcare-related fields available in the dataset

## 5. Key Features

- Six dashboard pages
- Interactive data visualizations
- KPI cards and charts
- Patient demographic analysis
- Hospital operations analysis
- Clinical and financial data exploration
- Pharmacy-related analysis
- Interactive filters, where configured

## 6. Project Objective

The objective is to demonstrate practical data analytics skills by preparing, analyzing, and visualizing healthcare data using Power BI.

## 7. How to View the Project

1. Download the `.pbix` project file.
2. Open it using Microsoft Power BI Desktop.
3. Navigate through all six dashboard pages.
4. Explore the visualizations and available filters.

## 8. Conclusion

This project demonstrates how Microsoft Power BI can be used to organize healthcare data and present it through interactive dashboards for data exploration and reporting.
